# Day 11 — Product Review Sentiment Analyzer

**Phase 2 – NLP & Text AI | UnProf.ai Internship**

A Python tool that classifies product reviews as **Positive**, **Negative**, or
**Neutral**, counts each category, and visualizes the results with a bar
chart and a pie chart.

## 📌 Project Overview

Sentiment Analysis is an NLP technique used to determine the emotional tone
behind text. This project applies it to a dataset of **100 product reviews**
to simulate a real-world use case: understanding customer feedback at scale
(e-commerce, social media monitoring, brand analytics).

## 🧠 Approach

1. **Dataset (`reviews.csv`)** — 100 short product reviews (mix of clearly
   positive, clearly negative, and neutral/mixed opinions), generated by
   `generate_dataset.py`.

2. **Sentiment scoring** — each review is scored two ways:
   - **TextBlob** — returns a *polarity* score from `-1` (very negative) to
     `+1` (very positive), based on pattern-matching against a lexicon of
     adjectives.
   - **VADER (Valence Aware Dictionary and sEntiment Reasoner)** — returns a
     *compound* score from `-1` to `+1`. VADER is specifically tuned for
     short, informal text (like reviews and social media), and accounts for
     intensifiers ("very good"), punctuation ("great!!!"), and negation
     ("not good").

3. **Classification** — the standard VADER thresholding rule is applied to
   the compound score:
   - `score >= 0.05` → **Positive**
   - `score <= -0.05` → **Negative**
   - otherwise → **Neutral**

   The final label for each review uses the **VADER classification**, since
   VADER generally performs better on short, informal review-style text.
   Both scores are still saved to the output file so you can compare them.

4. **Output** —
   - `reviews_with_sentiment.csv`: original reviews + TextBlob score/label +
     VADER score/label + final sentiment.
   - `sentiment_summary_chart.png`: a bar chart and pie chart showing the
     count/percentage of each sentiment class.
   - Console printout of total counts per sentiment.

### Offline fallback

If `textblob` or `vaderSentiment` aren't installed, the script automatically
falls back to a small built-in keyword-based scorer so it still runs
end-to-end without internet access. **Install the real libraries (see
below) for accurate, production-quality results** — the fallback is only a
safety net.

## ▶️ How to Run

1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```
   (First time only, TextBlob needs its small corpora):
   ```bash
   python -m textblob.download_corpora
   ```

2. **(Optional) Regenerate the dataset**
   ```bash
   python generate_dataset.py
   ```

3. **Run the analyzer**
   ```bash
   python sentiment_analyzer.py
   ```

4. Check the outputs:
   - Console: total count of Positive / Negative / Neutral reviews
   - `sentiment_summary_chart.png`: bar chart + pie chart
   - `reviews_with_sentiment.csv`: full labeled dataset
